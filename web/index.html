Official dataset source

MS MARCO is a large-scale information retrieval dataset. The passage collection has about 8.8 million passages; the hosted research runtime supports samples of up to 10,000 passages and 15 MB.

03 / RESEARCH DESIGN

How MS MARCO is used here

Retrieval corpus

Passages from MS MARCO are used as real-world text candidates for hybrid retrieval and evidence inspection.

Ranking evaluation

Use query/qrels files separately to evaluate ranking quality with MRR@10 or other retrieval metrics. This UI loader currently loads the passage collection only.

Poisoning evaluation

MS MARCO is not itself a poisoning-labelled dataset. Security experiments require a separate, explicitly documented attack-injection protocol and held-out labels.
